# Функциональная чистка — 13 октября 2026

- Понгсы, паки, ежедневные награды и задания удалены из интерфейса и действующих API. Начисления при регистрации, матчах, турнирах, достижениях и мини-играх удалены. Исторические записи базы сохраняются.
- Пользовательские уведомления и их отправка удалены. Сообщения об ошибках, подтверждения действий и вибрация остаются.
- Игры скрыты, старые адреса ведут на главную. Физика, серверная проверка результатов и история мини-игр сохранены без валютных наград.
- Карточку даёт только подтверждённая победа над зарегистрированным игроком **на турнире**. Товарищеские матчи, гости, тестовые турниры и проходы без соперника не дают карточек. Повторный запрос не меняет коллекцию; один игрок — одна карточка. Старые карточки сохранены.
- Товарищеский рейтинг: новый игрок — 100, победа +10, поражение −10. Нижний предел не вводится. Старые значения не сбрасываются. Обработка результата и история выполняются в существующей транзакции. Турнирная модель не изменена.
- В профиле: имя/аватар и редактирование данных, установка на рабочий экран, карточки, статистика; управление только для ADMIN. Знакомства доступны с главной, товарищеские матчи — из товарищеского рейтинга. Управление форой и жалобами доступно администратору.
- Статистика: уникальные турниры с участием игрока со статусом LIVE/FINISHED (регистрация на будущий турнир ещё не участие), подтверждённые победы в матчах, завершённые турниры с игроком в качестве чемпиона. Тестовые турниры и встречи с гостями исключены. Пустая история даёт нули.
- Достижения скрыты, их данные и расчёт сохранены без валютных наград. Объяснение изменений рейтинга удалено из UI.
- Кнопки, меню и формы компактнее; мобильные кнопки сохраняют минимум 44 px по высоте. Нижняя панель содержит четыре пункта.

Миграция `011_functional_cleanup.sql` меняет стартовый товарищеский рейтинг только для будущих записей и добавляет журнал выдачи карточек по матчам. Таблицы пользователей, матчей, турниров и коллекций не удаляются. Существующий мигратор создаёт резервную копию файловой базы до миграции.

Основные файлы: `domain/cards.ts`, `domain/matches.ts`, `domain/skill-rating.ts`, `domain/players.ts`, `domain/tournaments.ts`, маршруты API, `Profile.tsx`, `Progress.tsx`, `Layout.tsx`, `main.tsx`, `styles.css`.
